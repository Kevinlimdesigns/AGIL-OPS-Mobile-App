# Research

Source-backed design research for the AGIL Ops Hub — Responder App. Each doc
states the established standard, cites credible sources (primary standards bodies
where possible), gives a verdict on where AGIL aligns vs. diverges, and
recommends fixes.

- [`typography-and-components.md`](./typography-and-components.md) — typography,
  text sizing, spacing/grid, touch targets, component dimensions, and
  public-safety field ergonomics.
- [`iconography-and-buttons.md`](./iconography-and-buttons.md) — icon system &
  usability, public-security symbology (ISO 7010, NFPA 704 / GHS,
  MIL-STD-2525 / NATO APP-6), buttons, and the mission-critical PTT & SOS controls.

**Relationship to other docs:** [`DESIGN.md`](../../DESIGN.md) remains the
canonical token spec; [`design-audit/`](../../design-audit/) holds the operative
audit rules, benchmarks, and source index. These research docs consolidate and
deepen that work into a single front-door reference and fill the gaps (esp.
iconography/symbology).
